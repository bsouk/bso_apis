⚠️  For IAP verification, you need a GOOGLE CLOUD SERVICE ACCOUNT JSON file.

📋 To get the service account JSON:
   1. Go to Google Cloud Console
   2. IAM & Admin > Service Accounts
   3. Create service account
   4. Create key (JSON format)
   5. Download the JSON file
   6. Save it as: config/google-service-account.json

📋 Then enable:
   1. Google Play Android Developer API (in Google Cloud)
   2. Grant service account access in Google Play Console
